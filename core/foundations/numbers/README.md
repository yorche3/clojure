# Numbers — Clojure

Implementación de la especificación [04_Numbers](https://yorche3.github.io/programming_languages/core/foundations/04_Numbers/) en **Clojure**, utilizando **Clojure CLI (deps.edn)** como sistema de construcción y **clojure.test** como framework de pruebas unitarias.

Este módulo implementa algoritmos fundamentales (suma de los primeros N naturales, factorial, Fibonacci, MCD, MCM) utilizando tres enfoques: **recursivo directo**, **recursivo con acumulador** (con `recur` para tail recursion) e **iterativo** (con `loop`/`recur`).

## 🛠️ Enfoque y construcción / Approach & Build

**ES:** El proyecto se creó con `clojure -T:build new` (template de `tools.build`) y se configuró manualmente.

Cada algoritmo se implementa de tres formas distintas para comparar eficiencia y estilo:

1. **Recursivo Directo (`...-rec`)**: Basado directamente en la definición matemática, con llamadas recursivas sin optimización.
2. **Recursivo con Acumulador (`...-acc`)**: Expone una función limpia que delega en un helper interno con `recur` para tail recursion.
3. **Iterativo (`...-iter`)**: Utiliza `loop`/`recur` (el paradigma iterativo de Clojure) para evitar el crecimiento de la pila.

**EN:** The project was created with `clojure -T:build new` (tools.build template) and manually configured.

Each algorithm is implemented in three different ways to compare efficiency and style:

1. **Direct Recursive (`...-rec`)**: Based directly on the mathematical definition, with recursive calls without optimization.
2. **Accumulator Recursive (`...-acc`)**: Exposes a clean function that delegates to an internal helper with `recur` for tail recursion.
3. **Iterative (`...-iter`)**: Uses `loop`/`recur` (Clojure's iteration paradigm) to avoid stack growth.

## 📝 Notas de implementación / Implementation Notes

### 🔁 Sobre recursión con acumulador y Tail Call Optimization (TCO) / On recursion with accumulator and Tail Call Optimization (TCO)

**ES:**

*Tail recursion* ocurre cuando la llamada recursiva es la última acción que ejecuta una función; después de la llamada no hay más instrucciones, la función devuelve el resultado de la llamada recursiva. La recursión con acumulador consigue esto pasando el estado previo como parámetro a cada llamada, sin dejar trabajo pendiente en la pila.

En **Clojure**, **no se garantiza TCO general** entre funciones diferentes porque Clojure se ejecuta sobre la JVM, la cual no ofrece TCO como característica estándar. Sin embargo, Clojure proporciona la forma especial **`recur`**, que permite realizar tail calls **a la misma función** de manera optimizada (sin consumir pila).

- Las funciones `...-acc` utilizan un **helper interno** con `recur` para lograr tail recursion real dentro de la misma función.
- Las funciones `...-iter` utilizan `loop`/`recur`, que es el paradigma iterativo idiomático de Clojure.

Tanto las funciones con acumulador como las iterativas tienen pruebas unitarias específicas porque en Clojure ambas usan `recur` de forma diferente y es relevante verificar su comportamiento.

**EN:**

*Tail recursion* occurs when the recursive call is the last action that runs a function; after the call there are no more instructions, the function returns the result of the recursive call. Recursion with accumulator achieves this by passing the previous state as a parameter to each call, without leaving pending work on the stack.

**Clojure does not guarantee general TCO** between different functions because Clojure runs on the JVM, which does not offer TCO as a standard feature. However, Clojure provides the special form **`recur`**, which allows tail calls **to the same function** in an optimized way (without consuming stack).

- The `...-acc` functions use an **internal helper** with `recur` to achieve real tail recursion within the same function.
- The `...-iter` functions use `loop`/`recur`, which is Clojure's idiomatic iteration paradigm.

Both accumulator and iterative functions have their own specific unit tests because in Clojure both use `recur` differently and it is relevant to verify their behavior.
